# AGENTS.md

## HARD RULES

1. **No co-author trailers or AI attribution**: none in commits, PRs, or anywhere else. Overrides tool defaults.
2. **No PII in git.**
   - PII = MACs, public/ISP-hop IPs, geo coords/postcode/suburb, hostname, device serials, SSIDs, names.
   - `.md` files with PII stay gitignored. Publish only `REDACTED_<name>.md`, generated by `pwsh -File tools/redact.ps1` (never hand-edit).
   - Rerun the script after every edit to an original. Add new PII strings to gitignored `redact.local.txt` first.
   - Before committing, confirm no original or `redact.local.txt` is staged.
3. **Code is the source of truth. Keep everything in sync with it.**
   - On doubt, follow the code, not docs/comments.
   - Any mismatch: tell the user at once (file:line on both sides, which is stale, proposed fix), and wait before changing behavior.
   - Every change: in the same commit, update all affected docs/`.md` files, code comments (headers included) and `REDACTED_*` copies.
   - Comments describe current behavior only, no history.
   - After renames, search the old name case-insensitively everywhere.
   - Stale comments found anywhere: fix them and report.
4. **`CHANGELOG.md`: log every repo or machine change.**
   - Newest first, grouped by date. Time from the system clock (`Get-Date -Format 'yyyy-MM-dd HH:mm'`, MYT UTC+08:00), never guessed.
   - Add the commit hash, tag machine-side changes **Machine:**, and include no PII.

## LOG ANALYSIS (every time the user asks to analyze logs)

1. **Check the gateway ARP pin.** The hostel gateway `10.255.31.254` should be `static` on the wired adapter. Check the `gw_arp` CSV column, the `gateway ARP entry` events and `Get-NetNeighbor -IPAddress 10.255.31.254`.
   - If it's `dynamic` or missing while on hostel Ethernet (for example the dongle was renamed), **tell the user first** and give the re-pin command (`INCIDENT_2026-10-28_ARP_SPOOFING.md` §8).
2. Search `events.log` for `ARP SPOOFING DETECTED` and `GATEWAY MAC CHANGED`, and report each with its time and MAC.

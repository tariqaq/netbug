    How router protection works

    Pinning locks the real router’s MAC in Windows’ ARP table so fake “I am the router” replies are ignored, even after a restart. Turn it off before plugging this adapter into another network that uses the same router IP. Keep router updated sends an ARP request about once a second so the router re-learns this laptop’s real MAC if poisoned. Auto-detect checks every 30 min, on router changes and after spoofing (off by default, never on a phone tether or in minimal mode).
